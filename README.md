# 🔍 Network Discovery and Vulnerability Assessment with Nmap

## Project Overview

This project demonstrates my practical understanding of network discovery, host enumeration, service identification, and vulnerability assessment using **Nmap (Network Mapper)**, one of the most widely used tools in cybersecurity and network security.

The objective of this project is to identify active hosts, discover open ports, detect running services, enumerate operating systems, and analyze potential security weaknesses within a target network. Through this exercise, I showcase my ability to perform reconnaissance and information gathering activities that form the foundation of penetration testing and security assessments.

## Skills Demonstrated

* Network Reconnaissance
* Host Discovery
* Port Scanning
* Service Enumeration

* Vulnerability Identification
* Network Mapping
* Cybersecurity Analysis
* Risk Assessment
